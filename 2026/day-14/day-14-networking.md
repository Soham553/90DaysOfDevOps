# Networking Fundamentals

   - Networking is sharing information between two devices over the internet.
   - Devices use a set of rules to transfer/share data from one to another.
   - There are many protocols present:
          - TCP/IP: Transmission Control Protocol
          - UDP: User Datagram Protocol

   - There is a theoretical model that explains how networking works.
   - It divided it into 7 layers
         - Application Layer
         - Presentation Layer
         - Session Layer
         - Transport Layer
         - Network Layer
         - Data Link
         - Physical Layer
