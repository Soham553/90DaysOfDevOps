# Git And GitHub

  What is Git?

    - Git is a version control system
    - Git tracks the history of changes in files or in a directory.
    - Developed by Linus Torvald.

  Need for Git?

    - The development process is not stable; every second code base needs to be updated according to the user or other factors.
    - Developers try new experiments daily.
    - While updating and experimenting then can face failures. Changes in the original code base cause the previous code to be lost (in the short term, the previous version)
    - Git playes importent tole in tracking the previous as well as the updated code base.
    - Developers get access to the previous version of the file, also.

 How does Git work?
 
    - git -v: To check the installed version of git on the local machine.
    - git init: Create the .git file where all the info about branches and commits is stored. 
    - git add <file_name>: Add file to track.
    - git commit -m <Message>: It will stage the change that done.
    - git log: can see the history.
    - git rm <file_name>: To remove a certain file from the tracking.
